========================================================================
نظام إدارة أصول التقنية وصيانة القاعات (IT Hub) - نسخة سطح المكتب المحلية
========================================================================

يعمل البرنامج محلياً بالكامل 100% بدون الحاجة للإنترنت أو استضافة سحابية،
مع حفظ قاعدة البيانات والتقارير تلقائياً على جهازك.

------------------------------------------------------------------------
الخيار 1: [ IT-Maintenance-Hub-Portable.exe ] (النسخة المحمولة)
------------------------------------------------------------------------
- يعمل مباشرة بالنقر المزدوج بدون تثبيت.
- مناسب للوضع داخل مجلد خاص أو على فلاش USB.
- عند التشغيل، ينشئ مجلداً محلياً بجانبه باسم [ IT-Hub-LocalData ] يحتوي على:
  * data\it-hub-database.json        (قاعدة البيانات المحلية + نسخة احتياطية تلقائية)
  * reports\                         (جميع تقارير Excel و PDF المصدرة من البرنامج)
  * backups\                         (النسخ الاحتياطية JSON المصدرة يدوياً)

------------------------------------------------------------------------
الخيار 2: [ IT-Maintenance-Hub-Setup.exe ] (نسخة التثبيت على ويندوز)
------------------------------------------------------------------------
- يثبت البرنامج على الجهاز وينشئ اختصاراً على سطح المكتب وقائمة ابدأ.
- يحفظ قاعدة البيانات والتقارير محلياً في مجلد المستندات:
  Documents\IT-Maintenance-Hub-LocalData\
  (داخل المجلدات: data\ و reports\ و backups\)

------------------------------------------------------------------------
الوصول السريع داخل البرنامج:
------------------------------------------------------------------------
- من الشريط العلوي: اضغط على [ المجلد المحلي ] لفتح مجلد البيانات والتقارير مباشرة.
- من مركز التقارير: يمكنك تصدير Excel شامل أو حفظ تقرير PDF محلياً بضغطة زر
  مع زر لفتح الملف أو مجلد التقارير فوراً.
========================================================================
